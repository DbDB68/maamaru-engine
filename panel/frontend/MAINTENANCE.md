# 前端维护说明

面板是给普通用户直接做决定的，不是脚本内部行为说明书。字段名称和帮助文字应优先回答“用户要选择什么”，避免解释轮询、识别、接管、回城等实现细节。

## 出阵配置

- 主区域顺序保持为：地图或难度 → 部队 → 出阵次数 → 战斗策略 → 特有高级设置。
- 高频、短选项放在主区域；长名单、低频设置和玩法特有配置放入二级入口。
- 能用开关表达的是非选择，不使用含义绕口的下拉框。
- 帮助问号只补充会影响用户决定的信息，不展示脚本如何监控或识别游戏。

### 自动行军

用户字段为“是否使用自动行军”。

- 开启：路线和阵形交给游戏，阵形设置隐藏；自动行军停止后，脚本仍负责安全检查、回城和手入。
- 关闭：脚本负责行军，因此展开阵形选择方式和兜底阵形。

上述接管行为属于实现约定，不应显示在用户界面。

### 独立手入

独立“手入”属于内部能力，不放在常用功能或配置导航中。日课与连续出阵仍会正常调用手入流程。原手入图标可在名单页面用于“手入黑名单”，不要因为隐藏入口而删除素材。

## 远征

“立刻远征”和“自动排班”必须作为两个清楚分开的区域展示：前者只在用户点击运行后派出，后者才会到点接管已经打开的游戏。不要使用“手动远征安排”这类容易与游戏内手动操作混淆的名称。

### 伤势处理

用户只需要配置“伤势停止条件”和“停止后的处理”。脚本在何时截图、如何持续检查、自动行军停止后何时接管等细节留在本文件和流程代码中。
