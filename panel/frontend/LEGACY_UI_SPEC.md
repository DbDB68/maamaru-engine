# 旧版像素界面复刻规格

本文件记录在 1280 × 720 桌面视口下，从 `/legacy` 实际渲染结果量取的组件规格。迁移时先复用对应 Vue 组件；不要在页面内重新定义同义尺寸与色板。

## 页面骨架

所有一级页面使用 `MaamaruFrame`。

| 项目 | 实测值 |
| --- | --- |
| 左上角 | `x: 110px; y: 232.8px` |
| 尺寸 | `1060 × 467.2px` |
| 木框 | `4.8px`（CSS 设计值 `5px`） |
| 外描边 | `1.6px`（CSS 设计值 `2px`） |
| 舞台 | `1060 × 173.2px` |
| 顶部导航 | `1060 × 47.6px` |

舞台内部高度沿用旧版响应式公式 `clamp(170px, 22vh, 220px)`，外加边框占用；`173.2px` 仅是 720px 高视口下的实测值，不得写死为所有窗口高度。

## 概览三栏

| 区域 | 宽度 | 高度 |
| --- | ---: | ---: |
| 常用功能 | `210px` | `429.6px` |
| 中央任务与日志 | `504.4px` | `429.6px` |
| 本丸统计 | `280px` | `429.6px` |
| 栏间距 | `12px` | — |

任务摘要卡为 `486.8 × 153.6px`。本丸统计资源砖高度为 `105.2px`，资源图标为 `32 × 32px`。

任务摘要的开始按钮使用狐金高亮、白字、`8px` 圆角和左侧播放符号；待命状态使用胶囊形硬边。日志内容框使用 `10px` 圆角，日志工具按钮使用 `6px` 圆角。

## 共用组件映射

| 视觉语义 | Vue 组件 | 使用位置 |
| --- | --- | --- |
| 一级木框 | `MaamaruFrame` | 概览、配置、近侍、系统 |
| 页面 / 面板页头 | `PanelHeader` | 统计、日志、近侍、系统、名单、排班 |
| 侧栏项目 | `SideNavItem` | 配置侧栏、系统侧栏 |
| 纸面卡片 | `PaperCard` | 任务配置、本丸统计、远征设置 |
| 原生表单控件 | `PixelControl` | 任务、近侍、系统、名单、排班、抽屉 |
| 高级名单抽屉 | `SwordListDrawer` | 南瓜、日课南瓜 |

## 页头变体

- `section`：普通卡片页头；像素主题为纸面硬边。
- `embedded`：嵌入配置页的名单与排班页头。
- `system`：系统页工具栏；使用米纸背景。

变体只允许改变已量取的布局用途，不得自行引入新色板。

## 侧栏项目

- 普通底色：`#e8dfca`。
- 普通边框：`2px solid #1a3055`。
- 选中底色：`#f1dea3`。
- 选中边框：`#c9a227`。
- 配置侧栏项目当前实测高度：`49.2px`。
- 系统侧栏项目当前实测高度：`44.2px`。

高度差属于两类信息密度差异，由父级用途控制；颜色、边框和状态含义由 `SideNavItem` 统一。

## 纸面卡片变体

- `task`：配置页的主要任务表单；保留任务状态、字段区和页脚操作。
- `dashboard`：本丸统计卡；桌面右栏实测宽度 `252px`，内边距 `14px 16px`。
- `settings`：远征与自动排班设置卡；内边距 `18px`。

页面不得直接重新声明同名纸卡结构；尺寸差异通过 `PaperCard` 的变体表达。

## 表单控件

`PixelControl` 直接输出原生 `input`、`select` 或 `textarea`，不增加影响盒模型的包装层。除复选框外，前端表单控件必须使用该组件。

- 像素主题纸底：`#fffaf0`。
- 文字与边框：`#1a3055`。
- 边框设计值：`2px`。
- 当前任务页下拉框实测高度：`38.4px`。
- 数字输入框实测高度：`38.7px`。

复选框保持原生控件，因为它与文本输入和选择框的交互语义不同；需要开关外观时使用已有的切换组件，不得把复选框伪装成文本控件。

## 复刻检查

每次抽取或修改共享组件后至少检查：

1. 生产构建和 TypeScript 检查通过。
2. 概览、配置、近侍、系统的 `MaamaruFrame` 坐标与尺寸一致。
3. 默认、悬停、选中、禁用状态没有引入新色板。
4. 日课南瓜与普通南瓜名单使用同一个抽屉组件。
5. 关键页面在实际浏览器中截图复核，不仅检查源码。
