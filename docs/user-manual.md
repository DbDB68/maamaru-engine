# まあ丸使用说明

这份说明写给第一次使用まあ丸的审神者。日常设置都可以在本丸面板中完成，不需要手动编辑配置文件。

> [!NOTE]
> まあ丸目前主要支持 MuMu 12 与 1280×720 游戏画面，已经过维护者长期实机运行，也有非技术用户完成安装和日常使用。游戏更新、新地图、不同模拟器或分辨率仍可能影响画面识别；第一次使用新任务或更换运行环境时，建议先短跑确认。

## 安装与启动

从 [GitHub Releases](https://github.com/DbDB68/maamaru-engine/releases) 下载最新版：

- `maamaru-setup-v*.exe`：安装版；
- `maamaru-launcher-v*.zip`：免安装版，解压后运行 `まあ丸启动器.exe`。

第一次启动：

1. 打开 MuMu 12，把游戏分辨率设为 1280×720，并进入《刀剑乱舞 ONLINE》。
2. 运行 `まあ丸启动器.exe`，等待检查完成。
3. 如果启动器没有找到模拟器，点击“选择模拟器”，选中 MuMu 安装目录。
4. 检查“程序文件”“用户数据”“运行环境”“面板端口”和模拟器相关项目；有提醒时先按提示处理。
5. 点击“启动まあ丸”，进入完整本丸面板；如果今天只想算账，点击“只打开账房”，不需要开启模拟器。

启动器常用按钮：

- **重新检查**：重新读取程序、端口、模拟器和 ADB 状态。
- **修复环境**：环境文件不完整或运行依赖异常时使用。
- **数据目录**：打开当前配置、日志和成绩单所在目录。
- **迁移数据**：把用户数据复制并校验到其他磁盘，详见[更新、卸载与数据迁移](#更新卸载与数据迁移)。
- **选择模拟器**：自动发现失败时，手动选择 MuMu 目录。
- **反馈错误**：面板打不开时，从启动器导出脱敏反馈包。
- **检查更新**：检查正式 Release；下载失败可以重试，安装前仍需用户确认。
- **只打开账房**：只开放家底、手动战绩、资源流水和活动规划，不连接模拟器，不运行任务、远征排班或机器人。

## 面板怎么用

面板顶部主要分为“概览”“配置”“本丸”“近侍”和“系统”。日常运行主要使用前三项：

- **概览**：选择常用任务，查看当前任务、可视化日志、本丸快照、远征、内番和今日日课结果。
- **配置**：查看每项任务的完整设置并保存。
- **本丸**：在“成绩单”查看资源变化与任务记录，在“规划”安排资源目标和活动打算。

纯净账房入口只保留“本丸账房”。它与完整模式读取同一份本地账本，但麻麻露自动完成的任务和审神者手动报备的战绩仍分开记录；打开账房本身不会唤醒游戏或补跑排班。

每项任务都有以下操作：

- **保存配置**：保存当前选项，下次继续沿用。
- **开始任务**：立即按当前页面的设置运行。
- **紧急停止**：直接终止当前任务。停止后先看一眼模拟器停在哪个页面，再决定是否重新运行。

同一时间只能运行一项任务。任务开始后可以切回概览或日志页面，不需要一直停留在配置页。

### 第一次运行前检查

- 地图、部队、次数和结束动作是否正确；
- 部队没有重伤成员，御守和刀装符合自己的习惯；
- 手入黑名单、刀解白名单和活动目标名单已经检查；
- 自动补充手形或提灯是否允许消耗小判；
- 自动手入是否可能消耗加速符；
- 自动补充刀装是否允许消耗现有刀装；
- 电脑休眠、关闭模拟器等结束动作不会影响其他正在运行的事情。

## 一键日课

一键日课可以自选以下步骤：登录、签到、万屋、演练、远征、内番、锻刀、刀解、合成、出阵、任务奖励和库存快照。不勾选的步骤不会执行。

使用方法：

1. 在“配置”中选择“一键日课”。
2. 勾选今天需要执行的步骤。
3. 如果勾选“出阵”，在“出阵安排”中选择联队战、南瓜大作战、异去、大阪城或普通合战场，并填写地图、部队和次数。
4. 选择任务结束后保持待命、退出游戏、关闭模拟器或让电脑休眠。
5. 保存配置后开始任务。

日课中的地图、部队和次数在日课页面填写；阵形、自动行军、伤势处理、自动补刀装和自动换队长等战斗规则，会沿用对应“合战场”“异去”或“大阪城”独立页面的设置。修改战斗规则时，不需要在日课里再配一遍。

每一步都会单独记录成功或失败。某一步失败后，后续步骤仍可能继续执行；结束后请看日课结果，不要只根据最后一个页面判断整套日课是否完成。

锻刀步骤只使用当前空闲炉，不会为了凑满日课次数消耗加速符。库存快照通常在锻刀收工时顺路完成；如果没有执行锻刀，日课才会在收尾时单独盘点。

## 出阵的共用设置

普通合战场和异去共用大部分战斗设置，大阪城也沿用伤势处理与补刀装规则。

### 自动行军与阵形

- **使用自动行军**：成功开启后，路线和阵形交给游戏处理；まあ丸只观察任务完成、自动行军停止和伤势中断。
- **手动行军**：由まあ丸处理岔路和阵形。阵形可选手动或自动：手动固定使用所选阵形；自动交给游戏，游戏无法判断（索敌失败等）时まあ丸优先选择有利阵形，认不出再落回所选阵形。从手动切到自动只会影响下一次阵形选择，まあ丸仍会把当前这一场选完；确认阵形页面真正消失后才会继续战斗。

### 伤势停止与手入

- **伤势停止条件**：可以选择轻伤、中伤或重伤。无论配置哪一级，确认重伤时都不会强行出阵。
- **手入加速后继续**：修好当前出阵部队并使用加速符，然后继续剩余圈数。
- **手入后停止**：把符合条件的刀送去手入，本次任务不再续跑。
- **停止且不手入**：返回或停止点击，把后续处理留给玩家。

手入黑名单中的刀不会被自动送去手入。连续出阵使用“手入加速后继续”时，只处理当前出阵队，不读取独立手入工具的队伍设置。

### 自动补充刀装

自动补刀装与手入方式是两个独立开关。即使选择“手入后停止”或“停止且不手入”，也可以单独决定是否补刀装。

开启后，まあ丸会在首次出阵前把当前部队保存到游戏的“记录一”。只有点击出阵后实际出现“刀装未满”提示，才会尝试用记录一恢复并重新检查伤势。请不要在任务运行期间手动覆盖记录一。

### 自动换队长

合战场和异去可以开启自动换队长，并选择 5、10 或 20 点疲劳差阈值。まあ丸会在每圈出阵前读取当前部队疲劳，把符合阈值的成员调整到队长位。

队长已经合适、疲劳差不足、疲劳读取失败或拖动没有生效时，不会强行继续调整。它是战斗内策略，不是需要单独运行的任务；一键日课会沿用对应页面的开关和阈值。

### 王点前撤退

王点前撤退只在普通合战场关闭自动行军后生效：

1. 在“合战场”中关闭自动行军。
2. 打开“王点前撤退”。
3. 选择地图、部队、圈数和伤势处理方式。
4. 第一次在新地图使用时先短跑，观察日志能否稳定报告小地图状态。

まあ丸会读取右上角小地图，确认下一步将进入王点时主动返回本丸。小地图无法确认时会继续普通行军，不会把“不知道”当成撤退信号。

王点前撤退完成也算一圈。它可以避免地图因反复击破王点而出现检非违使，但不能移除已经出现的检非违使。

## 出阵与活动任务

| 任务 | 主要设置与边界 |
|---|---|
| **普通合战场** | 选择章节、小图、部队和圈数；支持自动或手动行军、阵形、伤势处理、补刀装、自动换队长和王点前撤退 |
| **异去** | 当前开放第一章 1～4 图；可设置圈数和是否用小判补充提灯，并沿用战斗共用设置 |
| **大阪城挖地** | 可指定已解锁的 1～99F 连续挂机；未指定时不选择楼层，只按游戏当前流程持续点击“行军”。没有游戏自动行军，支持阵形、伤势处理、手入续跑、补刀装和小判掉落率实验 |
| **江户城潜入调查** | 只智能跑 E4，其他难度不计划适配；选择部队、阵形、出阵次数和是否补充手形，每圈结算后记录带回的钥匙 |
| **联队战** | 按次数运行；手形不足时可以停止，或在明确开启后用小判补充。当前主要按 4 图配置 |
| **南瓜大作战** | 选择难度、部队和次数，可按目标名单识别剪影并在令牌预算内换板；当前不会自动购买补充令牌 |
| **刷花** | 选择部队和位置，让对应成员单挑 1-1；疲劳达到目标后换下一位或结束 |
| **演练** | 选择部队和阵形；读取对手阵容，优先挑战更容易处理的目标，并记录能够确认的胜负 |

### 大阪城指定楼层

需要固定挂机时，打开“指定挂机层数”并填写已解锁的 1～99F。不开启时，まあ丸不会选择楼层，只在进入大阪城后按游戏当前流程持续点击“行军”；楼层如何推进由游戏决定。

“小判掉落率实验”会记录能够确认的楼层、圈数和小判变化，用于本地成绩单估算；识别失败不影响挖地本身，也不会硬猜收益。

活动入口、页面布局或规则更新后，如果まあ丸无法确认楼层或行军状态，会停止而不是盲目继续点击。

### 江户城潜入调查

江户城只智能跑 E4，其他难度不计划适配。まあ丸会读取剩余步数，优先经过设定路线中的节点，并在无法继续巡游时转向王点：

- “出阵次数”填 `0` 时，会使用当天已有手形继续运行，直到无法再出阵；填写具体数字时最多运行对应圈数。
- “是否补充手形”关闭时，手形不足便结束；开启后才允许在游戏补票弹窗中使用小判。弹窗无法确认时不会盲点消费。
- 江户城没有游戏自动行军，但每场战斗仍可选择手动或自动阵形；手动固定使用所选阵形，自动模式识别失败时优先选择有利阵形、认不出再落回所选阵形。
- 中伤可以继续巡游，确认重伤时仍会拦截出阵；页面、步数或战斗状态连续无法确认时会安全停止。
- 每圈结算会记录带回的钥匙、耗时和圈数，供“全部记录”和活动算盘使用。

当前巡游路线、识别范围和活动入口按本期实机画面制作。现有少量实测记录里钥匙表现不错，但不能据此保证每圈收益；活动复刻或游戏改版后，第一次运行请先只跑一圈观察。

### 活动资源消耗

- 联队战手形与异去提灯只有在开启自动补充时才会使用小判；关闭后资源不足即结束。
- 南瓜大作战的令牌自动购买目前禁用，令牌不足时结束。
- 江户城只有开启“是否补充手形”后才允许使用小判；无法确认补票弹窗时结束。
- 开启自动补充前先确认次数和小判余额，避免把测试配置留成长期挂机配置。

## 远征、锻刀与其他独立工具

### 远征与自动排班

“远征”和“自动排班”是两种不同用法：

- **远征**：现在立即收取已经归来的队伍，等待十分钟内即将归来的队伍，并按“常用安排”重新派出；等待更久的本次跳过。
- **自动排班**：在设定时间接管已经打开的游戏并派遣。到点时面板、模拟器和游戏都必须保持开启。

配置自动排班后要点击“保存排班设置”。临时不希望まあ丸接管时，可以暂停 30 分钟、1 小时或今天不接管，不必删除原排班。

### 锻刀

独立锻刀会先收取已经完成的刀，再给空闲炉点火：

- “最多锻几炉”是本次上限，不会占用正在工作的炉；
- 不使用加速符；
- 可以添加一个或多个目标时长，命中后通过已配置的通知渠道报喜；
- 收取结果能够认出刀名时，会进入成绩单的“掉落结果”；认不出时只保留已确认的收取事件，不编造名字。

锻刀会消耗木炭、玉钢、冷却材、砥石和委托符。开始前请确认配方、空闲炉、刀位和资源余额。

### 炼糖

炼糖是“收件箱领取刀剑 → 进入习合循环”的按需工具，不属于一键日课。它会消耗可以作为习合素材的重复刀剑：

- 进入习合列表后，只会点击列表中的第一把刀作为本体；
- 开始前请在游戏中保持开启“隐藏无法习合的刀剑”；
- 游戏中已上锁的刀无法被一键选择；
- 所持满、没有可喂的重复刀、收件失败或达到安全上限时结束；
- 第一次使用请在旁边观察，确认收件箱筛选、上锁状态和习合目标符合预期。

炼糖没有额外的刀名白名单，不要把“上锁保护”误解成项目会替你判断哪些刀值得保留。

### 库存快照

库存快照会手动读取八种资源并刷新本丸看板。平时锻刀收工和运行中的顶栏观察会顺路更新数据，通常不需要专门执行。

以下情况可以单独运行：

- 想立刻刷新看板；
- 日课没有执行锻刀，需要补一次完整盘点；
- 最近一轮挂机缺少收工盘点，而且挂机结束后没有进行任何会改变库存的操作。

## 名单与资源安全

- **手入黑名单**：名单中的刀不会被自动送去手入。
- **刀解白名单**：只有明确允许的刀才会进入自动刀解范围。
- **合成与活动目标名单**：限制对应流程可以选择或处理的刀剑。
- **游戏上锁状态**：炼糖依赖游戏本身的上锁保护，不使用刀解白名单。

第一次运行手入、刀解、合成、炼糖或活动目标筛选前，请打开名单页面检查并保存。涉及刀剑、小判、加速符、刀装和锻刀资源的操作，不要只依赖默认值。

## 成绩单怎么看

成绩单只记录まあ丸能够确认的事情。进入过页面或点过按钮，但没有确认结果，不会直接算作成功。

### 规划页

“本丸 → 规划”先展示已经立下的目标，再展示活动日程和新增目标入口。

- 选择“攒到多少”时，填写目标资源数量，狐之助会根据近期普通日子的净收支估算大约哪天攒够。
- 选择“到哪一天”时，填写截止日期，狐之助会估算到期时大约有多少资源。
- 活动期间和平常进账方式不同，能够识别的活动会按活动规则单独计算，不把活动日的异常收支直接当成长期速度。
- 江户城活动卡会按钥匙总量、免费手形、场均钥匙和精确结束时间估算补票小判；场均钥匙优先使用本期实测，没有数据时可以先填估计。
- 大阪城目标填写的是活动结束时希望留下的小判库存，不是“准备花掉多少”；狐之助会从当前家底计算差额、剩余层数和预计工时。

预测只是一份基于现有记录的打算。库存记录不足、活动规则未知或剩余时间不够时，页面会明确说明，不会伪造一个确定答案。

当前成绩单分为 **概览** 和 **全部记录**。概览可以切换最近 24 小时、7 天和 30 天；全部记录通过日历查看最长一年的历史。

### 概览

- **顶部小结**：显示这段时间运行了多少次任务、出阵多少圈、演练胜负和变化较大的资源。
- **资源统计**：选择一种资源查看来源堆叠图，或勾选“对比几种资源”同时比较；点击某一天的柱子可查看当日来源和任务。
- **资源变化**：汇总木炭、玉钢、冷却材、砥石、小判、甲州金、委托符和加速符，并显示当前余额与账目可信程度。
- **狐之助小结**：只使用能够确认的玩法来源，直接指出主要获得和消耗；证据不足时不会硬猜。
- **掉落结果**：汇总出阵、大阪城、南瓜和锻刀中成功识别的刀剑男士；点击“入手 N 振”旁边的“设置心愿刀”可直接进入名单，完整版也可从“配置 → 名单设置 → 心愿刀名单”进入，纯净账房则使用顶部“心愿刀”页。命中后会在本丸小结最前面额外报喜。名单不会自动删除，想继续刷二号机可以保留，不再需要时手动点掉即可。没有认出名字的记录不会冒充掉落结果。

“＋ 手动记账”下的三种记录含义不同：

- **记一笔收支**：一次填写这次获得或消耗的多种资源，正数是获得、负数是消耗；
- **补记一段活动**：记录玩家自己打的玩法、圈数和起止时间，自动算出圈速；
- **更新当前家底**：保存此刻看到的资源数字，作为库存快照。

玩家手动活动与まあ丸任务分开保存、分开计数；“全部记录”会用“你”标出手动记录。规划页需要圈速时，如果两边都有样本，会分别列出“まあ丸实测”和“你手动记的”，由玩家选择，不会混在一起求平均。

“我的手账”会按时间列出玩家自己补记的收支、家底和活动。每条都能修改或撤销；同一次操作中的多种资源仍作为一组一起纠正。这里只显示玩家手动记的内容，不混入まあ丸自动确认的流水和库存快照。

“家底概览”右上角的“账本进出”用来带走或带回记录：

- **导出 Excel 账本**：得到完整流水、当前家底、每日汇总和“可再次导入”五张表；想整理后再带回来时，只编辑“可再次导入”。
- **导出流水 CSV**：适合交给别的表格或分析工具，内容是完整流水。
- **选旧账预览**：支持 `.xlsx` 和 `.csv`。预览会先列出可导入、重复、冲突和无法识别的行，此时不会改账；有冲突时必须明确勾选确认。

まあ丸自动确认的流水只会导出，不能被旧表反向改写。真正导入前会先备份本地账本；重复记录会自动跳过，导入的内容会进入“我的手账”，以后仍能修改或撤销。

第一次打开空账房时，狐之助会用三步帮你安顿好：先抄一次现在的家底，再决定要不要导入旧账，最后可选立一个想盯的目标。旧账和目标都可以跳过；已经有任何家底记录的老用户不会看到这份引导。中途关闭会从当前步骤接着来，完成或选择“不需要引导”后不再出现。

24 小时概览会用纵向统计图把七种日常资源摊开（甲州金保留在账上，但不塞进日常变化图）：每柱按自身变化归一显示、按来源分色，柱顶保留真实数额，因此数量级相差很大的小判、四资源和符都看得清。7 天和 30 天仍按单种资源查看时间趋势，也可以手动选择少量资源对比。

### 三类数据不要混在一起

- **流程确认**：まあ丸在任务中确认完成的出阵、远征、领奖、锻刀、手入等事件。
- **库存实际变化**：两次完整库存读数之间真实识别到的数字差值。
- **玩家补充说明**：玩家主动说明两次任务之间做过什么，只补充上下文，不修改库存事实。

运行中顺路看到的一次顶栏库存只是“途中观察”，不能单独算成本轮收益。只有能够形成前后边界的库存读数，才会产生可信的资源变化。

流程确认的收支与库存变化对不上时，差值会单独保留。可以点击“这期间做过什么”，选择大概时间和操作类型；也可以选择“记不清了”“没有其他操作”或“不想说，记差值就好”。

### 资源变化与掉落结果

![资源变化与掉落结果](assets/report-resource-summary.png)

“仅供参考”“基本可信”或“账目完整”描述的是当前时间段的库存证据是否连续，不代表任务本身成功或失败。可信程度会综合当前范围内各资源的读数数量、连续性和数据缺口；需要判断某一天时，再点击图表查看当天明细。

掉落结果只展示识别成功的名字和来源。识别失败时可以从全部记录和日志确认任务是否完成，但不会补一个猜测的刀名。

### 全部记录

![按日期查看全部记录](assets/report-daily-records.png)

“全部记录”使用日历选择日期，并把当天的任务和活动放在一条时间线上：

- 一轮任务可以展开查看轮内出阵、远征、领奖、锻刀和资源收支；
- 江户城会显示完成圈数、实际耗时以及每圈带回的钥匙；
- 没有所属任务的活动才单独显示，避免同一件事出现两次；
- 系统观察和诊断细节放在更深层，不占满玩家时间线；
- 轻量任务记录与玩家说明长期保留，体积较大的 OCR 观察明细默认保留 90 天。

### 收工盘点失败时怎么补

只有**最近一条有开工盘点、但没有收工盘点的挂机记录**可以补盘：

1. 挂机结束后不要领取邮箱、任务奖励，也不要锻刀、手入、购买或进行其他会改变库存的操作。
2. 单独运行一次“库存快照”。
3. 打开“全部记录”，找到最近一轮挂机并点击“补上最近盘点”。
4. 确认这份快照没有被其他操作污染。

如果挂机结束后已经做过其他操作，就不要补盘。较晚的库存无法区分哪些变化来自挂机、哪些来自玩家，强行补上只会制造一份看似完整但实际错误的收益记录。

### 演练成绩

まあ丸会读取当前刷新场已经留下的胜利或败北章，把已有胜场计入本次目标，避免同一刷新周期重新运行时从零开始。结果没有明确识别时会标为待确认，不会直接当成败北或零胜。

成绩单保存在本机，只覆盖まあ丸执行并已经接入结构化记录的玩法。它不会读取游戏账号后台，也不能自动补全玩家没有说明的手动操作。

## 任务为什么停了

常见的安全停止原因：

- 检测到重伤或达到设置的伤势条件；
- 刀装不满，且没有开启或无法安全完成自动补充；
- 手形、令牌、提灯、小判或锻刀资源不足；
- 游戏更新、网络异常或弹窗没有恢复；
- 当前页面与设置的地图、楼层或活动入口不一致；
- 疲劳、阵形、王点或楼层等关键状态无法可靠确认；
- 一段时间没有任务进度，看门狗结束了可能卡死的进程。

处理顺序：

1. 查看日志最后几条可视化消息。
2. 看模拟器当前停在哪个页面。
3. 确认是配置不匹配、资源不足、游戏更新还是识别失败。
4. 修正原因后再运行对应任务，不要在原因不明时反复重跑整套日课。

紧急停止会直接结束任务进程，无法保证执行收工盘点或回到本丸。停止后请先确认模拟器页面和部队状态。

## 反馈错误

面板能打开时，点击日志右上角的“反馈错误”；面板打不开时，在启动器中点击“反馈错误”。把生成的 ZIP 和问题发生时的完整模拟器画面一起附到 [GitHub Issues](https://github.com/DbDB68/maamaru-engine/issues)。

反馈包只收集版本、系统摘要、启动失败记录、最近任务日志和少量框架文本日志。它不会包含まあ丸配置、API Key、聊天记录、库存、状态数据库或截图，并会遮掉本机用户名路径和常见密钥字段。上传前仍可自行解压查看。

提交问题时请说明：

- 使用的まあ丸版本；
- 模拟器与分辨率；
- 运行的任务和主要设置；
- 最后看到的日志与模拟器画面；
- 是否能稳定复现。

## 更新、卸载与数据迁移

### 更新

在启动器中点击“检查更新”，下载后确认安装。更新只替换程序文件，不删除用户数据；下载会校验官方 Release 文件的名称、大小和 SHA-256，安装失败时尝试恢复旧程序。

### 用户数据

安装版默认用户数据目录：

```text
%LOCALAPPDATA%\Maamaru
```

其中包含配置、排班、日志、成绩单、识别素材覆盖和备份。源码开发版默认使用 `%LOCALAPPDATA%\Maamaru-Dev`，与安装版分开；两者都使用本机 `8080` 端口，不要同时运行。

### 迁移数据

在启动器中点击“迁移数据”，选择新目录。まあ丸会先完整复制并逐文件校验，再让下次启动切换到新目录。原目录会继续保留；确认新目录能够正常启动后，才可以另行清理旧副本。

复制或校验失败时仍继续使用原目录。不要在迁移过程中手动移动、合并或删除两边文件。

### 卸载

卸载时可以选择保留用户数据，适合换盘、重装或以后继续使用；只有明确选择不再使用并二次确认后，才会删除 `%LOCALAPPDATA%\Maamaru`。

## 仍然不确定怎么配

可以把仓库交给支持项目协作的 Agent，让它先阅读 [`agent-user-guide.md`](agent-user-guide.md)，然后直接描述目标，例如：

> 帮我检查まあ丸，让部队三去 8-1 打十圈；中伤就修好并继续，结束后保持游戏开启。

Agent 应当替你检查现有配置和日志，只询问会实际改变任务结果的必要信息。
