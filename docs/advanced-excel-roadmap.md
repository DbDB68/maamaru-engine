# 本丸账房后续路线

目标不是继续堆图表，而是把“高级 Excel”真正闭环：账能看懂、填错能救、旧账能带进来、自己的账能带走。

## 当前进度

- [x] 账房与规划串联：资源卡显示近日平常日均、目标差额和预计达成日期，并可直达规划。
- [x] 我的手账：统一查看手动收支、手动家底和手动活动；支持修改与撤销。
- [x] 导入导出与备份：导出完整流水、当前家底和每日汇总；导入旧表前先预览、提示冲突并自动备份。
- [ ] 空账本首次引导：抄一次当前家底，可选导入旧账，再立一个想盯的目标；完成后不再打扰。

## 当前开工项

下一步做“空账本首次引导”：只在还没有家底记录时出现，带玩家抄一次当前家底；旧账导入和建立目标都可跳过，完成后不再打扰。

## 暂不抢跑

库存余额曲线、与上周比较、异常大额变化等属于后续增强。先真实使用一段时间，再决定是否值得做，避免把本丸账房堆成企业 BI。
