# まあ丸近期待办

更新于 2026-09-27。这里只记当前方向和待确认的问题，不把讨论中的想法写成已经定稿的功能规则。

## 先想清楚：规划与自动化的边界

- [ ] 重新梳理资源规划怎样服务自动化：玩家可指定「想额外获得多少某种资源」（可带期限），不要求先填写保底库存；没指定时，先只考虑锻刀短板和小判。锻刀按配比与方式计算四材料、委托符及按需使用的加速符，未知库存不猜；小判不设“够了”的硬线，有余力就建议继续攒。玩家可改选。暂不做刀剑男士练级建议。今天想打多少圈、什么时候派远征，仍要分清谁填写、谁估算、谁决定执行。
- [ ] 规划允许资料不完整；不能把录入整个本丸的刀账变成使用编队、出阵或远征的前提。已知、估算和未知要明确区分。
- [ ] 把“给玩家建议”和“替玩家执行”分开。资源预算、目标和时间安排怎样变成可选的执行设置，仍需结合真实使用再定。
- [ ] 远征收益先复核既有 `touken/data/expedition_maps.json`：已有 20 张图的大成功四资源数额；按地点和结果计算普通成功／大成功，不把大成功当每次必得，不把活动加成或额外道具混进基础四资源。公开对照：[国服 BWiki 远征资源表](https://wiki.biligame.com/djlw/%E8%BF%9C%E5%BE%81%E8%B5%84%E6%BA%90%E8%A1%A8)、[国服官网远征攻略](https://touken.youzu.com/zixun/5052767.html)；接入建议前核对国服当前游戏画面和数值。

## 近期要做的功能

- [x] 本丸扫地识别并点过修行中的来信：狐之助报信、信件内容和读完后的提示；不因对话背后露出目录就误判已回到本丸。
- [ ] 内番使用游戏提供的免费肥料：先确认免费来源、库存和使用入口的实际画面，再接入内番流程；不擅自消耗付费或需玩家另作决定的道具。
- [ ] 继续记录刀装、宝物：先定“实际持有”“当前装备”“本次观察到”的不同口径；不要求玩家为使用现有自动化先补全所有资料，同款实例分不清时保留未知。
- [ ] 远征自动排班与任务流分工并行：明确同一时刻谁占用游戏、远征到点如何等正在打的一圈、最晚可顺延多久、错过班次怎样告知玩家。
- [ ] 活动规划与排班衔接：以联队战“今天目标圈数、实测圈速、远征放队时间”为例，给出可执行的挂机时段和圈数建议；先解决时间冲突与建议边界，再考虑自动开工。

## “我的本丸”的陪伴感

- [x] 把原先一条条的进程改成本丸动态：像微博／QQ 空间那样有发帖者、场景、文案和可追溯的执务记录，结果仍要看得清。
- [ ] 让手入的刀发动态。まあ丸已能在开工时认出是哪一振；使用加速符就按已修好呈现，没使用则先读游戏显示的手入时长，再计时到点呈现修好，不为此二次进游戏确认。玩家自行手动加速不由まあ丸追踪。文案可用对应刀的游戏原台词，先核对台词与角色。
- [ ] 参考 pazugiri 活动记录的“每天都有故事”的感觉，继续打磨排版、配图与文案；参考的是陪伴体验，不把截图素材直接搬进まあ丸。
