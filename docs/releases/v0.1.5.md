# まあ丸 v0.1.5

本次版本重点保护用户配置和运行记录，为后续安装器与自动更新打好基础。

## 主要变化

- 程序文件与用户数据正式分开保存。
- 安装版用户数据迁移到 `%LOCALAPPDATA%\Maamaru`，源码开发数据使用 `%LOCALAPPDATA%\Maamaru-Dev`。
- 首次启动自动迁移 v0.1.4 的配置、排班、状态、日志和用户识别素材。
- 迁移只复制、不覆盖、不删除旧文件，并自动留下备份和迁移记录。
- 用户识别素材改为覆盖模式，官方新增素材不会再被旧版整套副本挡住。
- 发布包新增版本和资源校验清单，为未来安全更新与回滚预留基础。
- 整理狐狸动画正式素材；制作母图和草稿不再混入程序仓库。

## 升级说明

下载并启动新版即可。首次启动可能显示已迁移的旧数据数量，这是正常现象。旧文件会继续保留，确认新版稳定前无需手动删除。

卸载或替换程序文件不会自动删除 `%LOCALAPPDATA%\Maamaru` 中的配置和历史记录。
