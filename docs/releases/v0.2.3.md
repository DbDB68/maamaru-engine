# まあ丸 v0.2.3

稳定性版本。一口气修掉四个实测翻车的 bug，并把库存盘点从"专程跑腿"改成"顺路随手拍"，任务整体更快更安静。

## 断网自愈（新能力）

- 挂机时模拟器断网（游戏弹"网络请求超时"）不再干等到天亮：脚本会识别超时弹窗，先试点确定，没用就自动重启模拟器、重新登录，并在"连接中断，是否从中断处重新开始？"弹窗点【是】接着断点继续打。
- 单次任务最多自动重启 2 次，防整夜反复重启；联队战与挖地循环已接入。

## 修复

- **异去卡死**：每日首次进异去的渐入剧情演出会让"决定"按钮先露脸再被盖住，脚本看一眼就动手正好点进动画里。现在等地标连续命中 3 次才算就绪，边等边点安全区推对话。
- **一键日课冷启动失效**：run 级开工库存盘点曾在打开游戏／登录之前触发，导致模拟器冷启动登录失效。盘点已挪进日课流程内，登录落本丸后才拍快照。
- **任务奖励领取卡死**：领完任务奖励少了"关闭任务列表"一步，弹窗留给下一个流程干瞪眼。现在收尾会认 ✕ 把窗口关掉。
- **演练误触**：等战斗结算时不再点屏幕中央（可能误戳对手行），改用右下角安全区。
- **独立「库存快照」脚本崩溃**：注册参数签名错位导致报"Agent 没有 status_snapshot_stream 方法"，已修复。

## 数据统计

- 库存盘点三层融合：巡逻顺路拍顶栏快照，完整快照融进锻刀收工，一键日课不再专程跑腿盘点，任务更利落。
- 成绩单接上挖地小判实验：显示小判收益、每小时速率与平均每层掉落。

## 升级

在まあ丸启动器中检查更新，下载并确认安装即可。安装器只替换程序文件，不会删除
`%LOCALAPPDATA%\Maamaru` 中的配置、排班、日志、统计数据与识别素材。
