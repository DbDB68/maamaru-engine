# まあ丸 v0.6.0 更新公告

亲爱的审神者：

您好！まあ丸 v0.6.0 现已正式发布。本次更新诚意奉上「自定义工作流」功能，并对面板进行了多项装修与改进。更新内容如下：

━━━━━━━━━━━━━━━━━━━━
一、新增功能
━━━━━━━━━━━━━━━━━━━━

1.【新增】自定义工作流。开模拟器、登录、签到、万屋、内番、远征、演练、锻刀、江户城、异去、领取任务奖励等日常操作现已全部做成积木，审神者可以按照自己喜欢的顺序自由拼接，拼好后一键执行，今日事务一次安排妥当。

2.【新增】工作流预设保存。拼好的流程可以取名存档，数量不限；常用流程可以钉到首页「常用功能」栏目，随点随跑。

3.【新增】一键日课升级。原有「一键日课」现已改为默认工作流，可在其基础上自由增删步骤，使用习惯保持不变。

4.【新增】结束后的安排。每条流程跑完后可选择：留在本丸／退出游戏／退出游戏并关闭模拟器／让电脑休眠。睡前挂一条流程，まあ丸干完活会自己收工，绝不吵醒您。

5.【新增】我的本丸个人首页。可登记审神者档案、就任日期与近侍刀，也可以写小记，留一句喜欢的话，给每次回来的自己。

6.【新增】小狐丸舞台搭档。近侍舞台迎来 Q 版小狐丸，支持双角色互动；页面向下滚动时舞台横幅会自动收起，不再遮挡正事。

━━━━━━━━━━━━━━━━━━━━
二、优化改进
━━━━━━━━━━━━━━━━━━━━

1.【优化】庭院背景支持自定义。系统设置新增「外观」栏目，内置六款预设配色及自选取色器，点击色块即可试穿，保存后长期生效。

2.【优化】常用功能支持自定义。不常用的功能可以隐藏，排列顺序可以随意调整。

3.【优化】远征卡片改为两行排版，地图名称不再被归来提示挤成竖排。

━━━━━━━━━━━━━━━━━━━━
三、问题修正
━━━━━━━━━━━━━━━━━━━━

1.【修正】江户城收尾时遭遇远征队归来结算屏会卡死的问题。现まあ丸会主动点穿结算屏继续干活，成绩单亦不再误报翻车。

2.【修正】库存快照中锻刀炉倒计时偶发「时间未识别」的问题。OCR 识别丢失冒号时现可正常读出时间。

3.【修正】一键日课收尾与下班模式同时触发时偶发卡死的问题。凌晨翻车实属冤案，现已平反。

━━━━━━━━━━━━━━━━━━━━
四、升级须知
━━━━━━━━━━━━━━━━━━━━

1. Windows 版用户可在启动器中检查更新。升级不会删除配置、成绩单、手账、小记、规划目标、日志、排班、备份及识别素材，请放心升级。

2. Android 离线试玩版（maamaru-ledger-demo-v0.6.0.apk）随本版继续提供，仍为独立试玩入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。

3. 正常管家模式仍主要支持 MuMu 12 与 1280×720 游戏画面；江户城仍只智能跑 E4，其他难度暂无适配计划。
