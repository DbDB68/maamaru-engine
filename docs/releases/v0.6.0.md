# まあ丸 v0.6.0

这次的头条是**自定义工作流**：把日课、远征、江户城、异去这些活儿拆成一块块积木，今天想干什么自己拼，拼好一键交给まあ丸。顺手还把面板装修了一圈——个人首页、小狐丸舞台、庭院背景都能按自己的喜好来。

## 自定义工作流

- 任务变成积木：开模拟器、登录、签到、万屋、内番、远征、演练、锻刀、江户城、异去、领任务奖励……按想要的顺序垒起来就是一条流水线。
- 垒好的流程可以起名保存，想存几条存几条；常用的可以钉到首页「常用功能」，点一下就跑。
- 一键日课也改成了同样的积木（默认流程），可以在它基础上加减步骤，顺手程度不变。
- 每条流程可以选「结束后的安排」：留在本丸、退出游戏、退出游戏并关模拟器、或者直接让电脑休眠——睡前挂一条，跑完自己收工。

## 我的本丸

- 新增个人首页：审神者档案、就任日、近侍刀，留一句喜欢的话给每次回来的自己。
- 可以写小记，本丸近况和执务记录也会在这里落脚。

## 舞台与庭院

- 近侍舞台迎来小狐丸搭档，有了 Q 版立绘和双角色互动；页面往下滑时舞台横幅会自动收起，不挡干活。
- 庭院背景可以自定义了：系统设置的「外观」里有六色预设和自选取色器，点色块立刻试穿，保存后记住。
- 常用功能可以自己收拾：不常用的藏起来，顺序随便排。

## 修好的冤案

- 江户城收尾时不再被远征队归来的结算屏卡死，会主动点穿继续；成绩单也不再把没跑完的圈误判成翻车。
- 库存快照里锻刀炉的倒计时，OCR 吃掉冒号时也能认出来，不再轻易「时间未识别」。
- 一键日课收尾撞上下班模式时不再卡死，凌晨的翻车冤案平反。

## 升级说明

Windows 版仍可在启动器中检查更新，升级不会删除配置、成绩单、手账、小记、规划目标、日志、排班、备份或识别素材。

Android 离线试玩版（`maamaru-ledger-demo-v0.6.0.apk`）继续随版构建，仍是独立试玩入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。正常管家模式仍主要支持 MuMu 12 与 1280×720 游戏画面；江户城仍只智能跑 E4，其他难度不计划适配。
