# まあ丸 v0.6.3 更新公告

亲爱的审神者：

您好！まあ丸 v0.6.3 现已正式发布。本次更新让活动账更聪明、收官更有仪式感。更新内容如下：

━━━━━━━━━━━━━━━━━━━━
一、新增功能
━━━━━━━━━━━━━━━━━━━━

1.【新增】活动收官小结。活动收摊后不再直接消失，「活动日程」会留一张小结卡七天：本期打了几圈、场均几把钥匙、共拿多少、四座宝库全开没有、补票花了多少小判，一笔一笔报清楚。本期数据同时归档，来年复刻时狐之助会参考本期实测。

━━━━━━━━━━━━━━━━━━━━
二、问题修正
━━━━━━━━━━━━━━━━━━━━

1.【修正】江户城活动账按剩余进度计算。此前无论已经打了多少圈，活动卡一律按从零开始报数（圈数、补票、小判预算全部虚高）。现已按「已拿多少、还差多少」算账：还差几圈全开、要补几张票、折合多少小判，一目了然。

2.【修正】隔夜中断的续打弹窗不再卡死任务。上次出阵被打断后重新登录，游戏会问「要不要从中断处继续」。对这种隔夜断点狐之助没有记忆，闭眼续打太危险，现在会自动选择「否」清掉中断数据返回本丸，任务从头正常跑。运行途中断网的自动续打不受影响。

━━━━━━━━━━━━━━━━━━━━
三、升级须知
━━━━━━━━━━━━━━━━━━━━

1. Windows 版用户可在启动器中检查更新。升级不会删除配置、成绩单、手账、小记、规划目标、日志、排班、备份及识别素材，请放心升级。

2. Android 离线试玩版（maamaru-ledger-demo-v0.6.3.apk）随本版继续提供，仍为独立试玩入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。

3. 正常管家模式仍主要支持 MuMu 12 与 1280×720 游戏画面；江户城仍只智能跑 E4，其他难度暂无适配计划。

━━━━━━━━━━━━━━━━━━━━

如您在使用过程中遇到任何问题，欢迎随时反馈。祝您游戏愉快，武运昌隆！

感谢您一直以来对まあ丸的支持！
