# まあ丸 v0.1.6

本次版本完成安装、更新、迁移和失败回滚闭环，为后续功能开发固定安全地基。

## 主要变化

- 新增无需管理员权限的 Windows 安装器，默认安装到当前用户的程序目录。
- 启动器可检查 GitHub 官方新版本，并把安装器下载到用户数据中的更新暂存区。
- 下载时核对官方地址、文件大小和 SHA-256；校验失败不会留下可执行的半成品。
- 安装前再次复核安装包并要求用户明确确认，不会静默升级。
- 升级前备份当前程序文件；安装失败时恢复旧版并重新启动。
- 安装、更新、回滚和卸载均不删除 `%LOCALAPPDATA%\Maamaru` 中的配置、日志与历史记录。
- 发布流程现在必须通过完整测试，并检查成品包含更新安全模块且没有混入用户数据。

## 从 v0.1.5 升级

在 v0.1.5 启动器中点击“检查更新”，确认下载并安装即可。升级期间会关闭启动器并显示安装向导；完成后新版自动启动。

若安装失败，更新助手会恢复升级前的程序文件。用户数据与程序备份分别保存，不会互相覆盖。
