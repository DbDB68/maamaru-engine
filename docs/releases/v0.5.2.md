# まあ丸 v0.5.2

这次主要做了两件事：让まあ丸出错时更会说人话，也把纯净账房从电脑里拿出一小块，做成可以装在 Android 手机上的离线试玩版。

## 异常与通知中心

- 面板顶栏新增铃铛。脚本崩溃、看门狗强制结束和一键日课未全绿时，会生成一张事故单，直接说明发生了什么、可能原因和现在该做什么。
- 同一种问题复发时只累计次数，不反复刷屏；可以点“知道了”，也可以在事情恢复后结案。一键日课下次全绿时会自动销掉对应事故。
- 事故单可以跳到相关页面。当前先负责在面板里把异常说清楚，QQ／ntfy 的播报规则没有在这一版贸然改动。
- 修复一键日课成绩单“实际红了一片，小结仍说没事”的问题：库存快照等收尾步骤没跑好时会如实标出。

## 日课冷启动更稳

- 一键日课现在优先通过 ADB 按游戏包名直接启动，不再依赖可能被 MuMu 广告遮住的桌面图标。
- 只有直启失败时才回退到图标识别，而且必须同时认出“刀剑乱舞”文字才会点击，避免把广告当游戏入口。
- 没有确认游戏成功启动时会安全停止并写进成绩单，不再在陌生画面继续盲点。

## 心愿刀与账目纠正

- 可以从成绩单“入手 N 振”旁边或名单设置中维护心愿刀；认出心愿刀入手时，本丸小结会把好消息放在前面。
- 资源差值需要审神者说明时，会先展示当天任务、操作时间和可能来源，减少面对一串数字猜自己当时做了什么。
- 独立账房的手账支持收支、家底和手动活动；撤销后会保留“后悔，放回来”入口，不要求立刻作决定。

## Android 离线试玩版

- Release 新增 `maamaru-ledger-demo-v0.5.2.apk`。打开就是黄色随身账房，不包含游戏自动操作。
- 可以手动记录资源收支、当前家底、活动圈数与时间，切换总览主资源并建立资源目标。
- “刀帐”可以记录刀剑男士等级、乱舞等级和备注。
- APK 没有联网权限，所有内容只保存在手机应用数据中，目前不会与电脑端まあ丸或纯净账房联动。
- 这是观察期试玩版，首次打开带有示例账目；卸载应用会同时清除手机里的试玩数据。

## 升级说明

Windows 版仍可在启动器中检查更新，升级不会删除配置、成绩单、手账、规划目标、日志、排班、备份或识别素材。

Android APK 是独立试玩入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。正常管家模式仍主要支持 MuMu 12 与 1280×720 游戏画面；江户城仍只智能跑 E4，其他难度不计划适配。
