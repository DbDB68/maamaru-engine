# まあ丸 v0.8.0 更新公告

亲爱的审神者：

您好！这次把「部队预设」从编辑页接到了实际任务里，也让联队战的海边之阵能跑完整圈。第一次使用新预设或活动时，仍请先跑一圈、看一眼结果。

━━━━━━━━━━━━━━━━━━━━
一、部队预设
━━━━━━━━━━━━━━━━━━━━

1.【新增】在预设中安排六个位置的刀剑男士，并可从出阵、活动、演练、远征或自定义工作流套用。预设没套完时，任务不会接着出发。

2.【新增】不录入完整刀帐也能按刀名和形态选人。套用时只从确认上锁的候选中选等级最高且唯一的一振；等级并列、锁或名单读不清时会停下请您处理。已从刀帐指定具体一振的旧预设仍按原来的身份核对。

3.【新增】可为每个位置指定各格刀装的种类与品级，以及宝物、马和御守。找不到指定装备、同款宝物无法区分或换装结果读不清时会停在出发前；空白格不会被擅自填满。

4.【说明】编队与换装仍属试用功能。请先用一支容易复原的队伍短跑验收，暂时不要把重要队伍交给无人看守的预设任务。

━━━━━━━━━━━━━━━━━━━━
二、联队战·海边之阵
━━━━━━━━━━━━━━━━━━━━

1.【新增】识别海边之阵界面，可按所选难度与部队出阵；游戏内自动行军委托已勾选时会继续使用，挂不上则回退手动打法。

2.【新增】出阵前会核对伤势、刀装和确认弹窗。三倍鱼笼只在读到持有数量大于零时才勾选；手形不足时，仅在您允许自动补充的条件下才使用小判。

3.【新增】特别合战场出现时，也能识别顶部「出阵」并完成确认。七彩夜光贝与活动累计夜光贝是两种东西，まあ丸不会把前者记入后者。

4.【修正】部队选择页或确认弹窗没有按预期打开时，会留图并停下，不再跳去尝试后续圈数却报「全部圈数跑完」。

━━━━━━━━━━━━━━━━━━━━
三、记录与升级
━━━━━━━━━━━━━━━━━━━━

1.【调整】秘宝之里的活动期次归档及相关活动信息读取更加稳妥；联队战累计夜光贝可用于本期规划。

2. Windows 版用户可在启动器中检查更新。升级只替换程序文件，不会删除 `%LOCALAPPDATA%\Maamaru` 中的配置、成绩单、手账、排班、备份和识别素材。老安装缺少的新设置会先备份原配置，再补齐缺失项。

3. Android 离线试玩版仍是独立账房入口，不连接游戏，也不与电脑端同步。

━━━━━━━━━━━━━━━━━━━━

如您在使用过程中遇到问题，欢迎保留现场画面并反馈。祝您游戏愉快，武运昌隆！
