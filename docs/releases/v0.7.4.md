# まあ丸 v0.7.4 更新公告

亲爱的审神者：

您好！まあ丸 v0.7.4 是一次提前送达的修复更新。秘宝之里令牌不足时，旧版会误用另一种补票界面，导致补充卡住、弹窗也关不掉；本次先把这项影响挂机的故障修好，不等待仍在试验中的编队功能全部完成。

━━━━━━━━━━━━━━━━━━━━
一、秘宝之里紧急修正
━━━━━━━━━━━━━━━━━━━━

1.【修正】令牌不足后，补充流程改为适配秘宝之里的滑条式界面：确认补充 1 枚令牌、确认小判消耗并收掉结果提示，不再卡在错误的“恢复一个”按钮上。

2.【安全】数量能读清时，まあ丸只接受补充 1 枚；若明确读到其他数量会停手请您查看。确认按钮异常反复出现时也会主动停止，避免连续误点。

3.【修正】补票没有完成时会尝试关闭残留弹窗，不再让弹窗挡住收尾回本丸。

━━━━━━━━━━━━━━━━━━━━
二、刀帐与本丸档案
━━━━━━━━━━━━━━━━━━━━

1.【新增】刀帐盘点加入头像辅助识别，与名字 OCR 互相核对；同名多振仍会逐振保留，认不准时继续诚实留作未确认。

2.【调整】刀帐入口、浏览、人工确认与培养标记重新收拢，盘点后可更直接地整理自己的本丸档案。

3.【新增】识别工具可查看和校准读取区域，为刀帐、编队等真机识别问题留下可复查的现场证据。

━━━━━━━━━━━━━━━━━━━━
三、日常使用调整
━━━━━━━━━━━━━━━━━━━━

1.【调整】流程工房、执务台、玩法设置和开发工具重新整理，常用任务与配置入口更集中。

2.【新增】远征排班补上“到点被占”的处理：不会无限等待或抢走玩家正在使用的游戏，会在超时后如实说明。

3.【新增】本丸加入今日时间表与跑况时间线，方便查看当天安排和任务进行到哪一步。

4.【修正】自动换队长改为按整列文字位置读取，队伍后排成员不再因漏读疲劳值而被忽略。

━━━━━━━━━━━━━━━━━━━━
四、编队功能说明
━━━━━━━━━━━━━━━━━━━━

1.【试验中】本版包含编队与预设编队的阶段性界面和执行器，但仍属于科研功能，尚不建议拿重要队伍做无人看守的日常操作。

2.【调整】换人后暂不再依赖 OCR 回读判定成败，避免正确换人被错误识别反过来报成失败。后续会在真机问题足够明确后再设计验收方式。

3. 本次发布的优先目标是让急需秘宝之里补票的审神者先恢复使用，不代表编队功能已经完成。

━━━━━━━━━━━━━━━━━━━━
五、升级须知
━━━━━━━━━━━━━━━━━━━━

1. Windows 版用户可在启动器中检查更新。升级只替换程序文件，不会删除 `%LOCALAPPDATA%\Maamaru` 中的配置、成绩单、手账、小记、规划目标、日志、排班、备份和识别素材。

2. 老安装会自动补齐本版新增的秘宝之里补票配置，不需要手工重建配置文件。

3. Android 离线试玩版仍是独立账房入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。
