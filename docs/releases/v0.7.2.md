# まあ丸 v0.7.2 更新公告

亲爱的审神者：

您好！まあ丸 v0.7.2 是一次**纯问题修复**版本，没有新功能。修的都是会导致任务卡死或没反应的实打实的故障，建议所有 Windows 版用户更新。

需要特别说明：**本版本中包含的「编队」相关功能仍处于科研阶段，尚不可用**，请不要尝试使用，后续版本成熟后会另行通知。本次发版仅为修复问题。

━━━━━━━━━━━━━━━━━━━━
一、问题修正
━━━━━━━━━━━━━━━━━━━━

1.【修正】登录时可能对着旧画面死点「今日不再弹出」。模拟器的画面通道在少数情况下会冻结（游戏早已回到本丸，脚本看到的仍是公告弹窗的旧画面），导致登录流程对着同一个位置反复点击、无法继续。现在画面通道会自检新鲜度，发现冻结会自动重连或切换备用通道，不会再原地死循环。

2.【修正】ADB 地址填错或模拟器端口漂移时，工作流会空等三分钟后放弃。现在会依次尝试 MuMu 标准端口和已连接的设备自动纠正，并在日志中提示正确的端口号。

3.【修正】面板日志页的「反馈错误」按钮点击没有反应。现在点击后会直接生成反馈包并在文件夹中替您选好，附到 Issue 里即可。

━━━━━━━━━━━━━━━━━━━━
二、升级须知
━━━━━━━━━━━━━━━━━━━━

1. Windows 版用户可在启动器中检查更新。升级只替换程序文件，不会删除 `%LOCALAPPDATA%\Maamaru` 中的配置、成绩单、手账、小记、规划目标、日志、排班、备份和识别素材。

2. 再次提醒：「编队」相关功能仍在科研阶段，当前版本无法正常使用，请忽略相关入口。

3. Android 离线试玩版仍是独立账房入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。

━━━━━━━━━━━━━━━━━━━━

如您在使用过程中遇到任何问题，欢迎随时反馈。祝您游戏愉快，武运昌隆！
