# まあ丸 v0.3.3

这次优先修复老安装升级后缺少新配置、任务没有真正运行却在成绩单中标绿的问题，并整理了出阵中的队长与刀装设置。

## 老安装会补齐新增配置

- 旧版已经存在的本丸配置会补上新版本新增的字段，包括异去地图坐标。
- 补齐只添加缺失字段，不覆盖审神者已经修改的路径、坐标和其他设置；写入前会在用户数据目录中留下备份。
- 异去、合战场或部队坐标缺失时，一键日课会把该步骤记为失败，不再出现“没跑却标绿”。

## 出阵可以自动换队长

- 合战场和异去新增“自动换队长”开关，默认关闭。
- 开启后可选择相差 5、10 或 20 点疲劳时换人；每圈出阵前读取当前部队，把疲劳最低的成员调整到队长位。
- 队长已经最累、差距未达到阈值或疲劳读取失败时不会强行调整；拖动没有生效会如实写入日志。
- 一键日课沿用对应合战场或异去页面中的开关和阈值，不再提供多余的独立换队长任务。

## 刀装与手入分别决定

- 合战场、异去和大阪城的“自动补充刀装”不再与“手入加速后继续”绑定。
- 选择“手入后停止”或“不手入并停止”时，也可以单独决定是否自动补刀装。
- 开启后，任务首次出阵前会保存当前部队到记录一；只有点击出阵后确实出现“刀装未满”提示，才会使用记录一补齐并重新检查伤势。
- 伤势达到停止条件时仍优先按审神者选择的手入方式处理，不会为了补刀装强行继续出阵。

## 任务奖励确认更稳

- 领取奖励后的观察窗口会持续等待报酬弹窗，弹窗出现较慢时不再误记为领取失败。

## 升级说明

在まあ丸启动器中检查更新，下载并确认安装即可。升级不会删除现有的配置、成绩单、日志、排班或识别素材。

自动换队长仍依赖当前 1280×720 游戏界面的疲劳识别与拖动操作，建议先用少量出阵观察本机识别是否稳定。
