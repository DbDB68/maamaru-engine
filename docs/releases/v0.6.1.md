# まあ丸 v0.6.1 更新公告

亲爱的审神者：

您好！まあ丸 v0.6.1 现已正式发布。本次更新诚意奉上「玩法规划」功能，并对炼糖与多项日常事务进行了可靠性修整。更新内容如下：

━━━━━━━━━━━━━━━━━━━━
一、新增功能
━━━━━━━━━━━━━━━━━━━━

1.【新增】玩法规划。本丸页新增「规划」签，选定玩法即可自动试算：异去会算出要刷多少圈、花多少工时、备多少小判，并直接指路该刷哪张图。

2.【新增】异去玩法数据卡。门票消耗、宝物碎片掉率、里程碑奖励与本期加倍活动一卡看全；活动花费现已拎成独立预算，不与日常开销混账。

3.【新增】资源目标指路。立下资源目标即附「去哪弄」获取途径卡；立小判目标会给出玩法建议。甲州金为氪金货币，现已移出目标清单，官方发放安排恕不代管。

4.【新增】短板监督。锻刀底盘按当前配比提示最先卡住的资源；博多小判另有消耗监督专卡，账上能动多少、已留预算多少，一目了然。

5.【新增】异去碎片差分记账。每圈结束时读取碎片库存弹窗做差分入账，自家掉率数据自此开始积累，越刷越准。

━━━━━━━━━━━━━━━━━━━━
二、优化改进
━━━━━━━━━━━━━━━━━━━━

1.【优化】我的本丸首页装修。新增管家小报与更充实的侧栏档案；本周小结改为周记版式，失败记录可精确定位到具体任务。

2.【优化】面板整体细节打磨。七个页面的圆角、按钮规格与字号层级已全面收齐，毛边尽去，风骨依旧。

3.【优化】工作流「我的流程」侧栏改为贴左缘整列排版，与系统设置导航同款，不再与编辑区挤作一团。

━━━━━━━━━━━━━━━━━━━━
三、问题修正
━━━━━━━━━━━━━━━━━━━━

1.【修正】炼糖五项修整：以连续无进展替代固定次数上限；持续习合同名本体不再被跳过名单挡路；黄锁只防当素材、不妨碍当本体的误解已纠正；一把都喂不动时，提示会先指刀位已满、再提可能上锁，说人话。

2.【修正】邮箱未清完时成绩单不再假装全绿，专项判分，收尾提示说人话。

3.【修正】自动远征现已会等待工作流跑完，并协调好队伍再续派，不再抢道。

━━━━━━━━━━━━━━━━━━━━
四、升级须知
━━━━━━━━━━━━━━━━━━━━

1. Windows 版用户可在启动器中检查更新。升级不会删除配置、成绩单、手账、小记、规划目标、日志、排班、备份及识别素材，请放心升级。

2. Android 离线试玩版（maamaru-ledger-demo-v0.6.1.apk）随本版继续提供，仍为独立试玩入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。

3. 正常管家模式仍主要支持 MuMu 12 与 1280×720 游戏画面；江户城仍只智能跑 E4，其他难度暂无适配计划。
