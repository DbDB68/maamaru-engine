# まあ丸 v0.3.2

这次主要补齐了干净 Windows 环境下的首次安装、模拟器连接、问题反馈和用户数据处理。

## 新安装会自动找 MuMu

- 配置里没有模拟器路径时，启动器会从 Windows 安装信息和常见 MuMu 12 目录中寻找 ADB 与 `MuMuManager.exe`。
- 只有两个程序都真实存在时才会写入空配置，不会覆盖审神者已经填写的模拟器路径。
- 自动识别不到时，可以在启动器点击“选择模拟器”，手动指向 MuMu 安装目录。

## 反馈错误更方便

- 面板日志和启动器都可以一键导出错误反馈包，可直接附在 Issue 中。
- 包内只有版本、系统摘要和少量文本日志；不收集配置、密钥、聊天、库存、状态数据库或截图，并会遮掉本机用户名路径和常见密钥字段。
- 反馈包自己也导出失败时，狐之助会提供一些不太稳定的精神支持。

## 用户数据可以搬盘

- 启动器新增“迁移数据”。まあ丸会先完整复制并逐文件校验，再让下次启动改用新目录。
- 原目录会继续保留；只有新目录重启通过检查后，才可以另行确认清理旧副本。
- 卸载时会询问是“换盘、重装或稍后再用”还是“不再使用まあ丸”。前者保留用户数据；后者经二次确认后才删除。

## 地图反馈截图收窄

- 王点前撤退的小地图识别成功时不再自动保存截图。
- 只有小地图没能识别时才保留反馈图，每次出阵最多 5 张。识别不明仍会继续普通行军，不会猜测王点并撤退。

## 升级说明

在まあ丸启动器中检查更新，下载并确认安装即可。升级不会删除现有的配置、成绩单、日志、排班或识别素材。
