# まあ丸 v0.2.0

这次正式把新版本丸面板和“本丸成绩单”推向 V2：小狐狸不只帮你干活，也会把自己能够确认完成的事顺手记下来。

## 本丸成绩单

- 按每次任务汇总出阵圈数、手入、加速符、补刀装和库存变化。
- 循环任务可查看实测平均圈速，并按 1 小时、6 小时、8 小时或自定义时长估算可完成圈数。
- 重复事件自动折叠，需要时可展开查看每圈明细。
- 任务奖励现在会识别可领取和灰色空状态，只在领取结果能够确认时计数。
- 统计仅作为本地辅助记录，不读取游戏账号后台，也不会把无法确认的行为猜成成绩。

## 出阵与日课

- 大阪城支持指定 1～99F 和挂机圈数；维护者实机完成了 88F 连续 120 圈。
- 连续作战中可自动补刀装，按配置手入、使用加速符并继续剩余圈数。
- 手入事件只在实际修复刀剑后计数；进入手入室但无需修复的情况不再误算。
- 一键日课的远征会按独立远征的“常用安排”收菜再派出，不与自动排班混用。
- 修正万屋已成功却在日课结尾被标记失败的可视化日志。

## 面板与文档

- 概览、任务、日志、本丸快照和成绩单形成统一的 V2 工作台。
- 像素主题优化长文本字体与自动排班组件，减少费眼的小字和突兀深色块。
- README 升级为 V2 介绍，补充特色功能、统计边界、实测记录与后续计划。

## 升级

在まあ丸启动器中检查更新，下载并确认安装即可。安装器只替换程序文件，不会删除
`%LOCALAPPDATA%\Maamaru` 中的配置、排班、日志、统计数据与识别素材。
