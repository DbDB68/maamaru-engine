# まあ丸 v0.3.5

这次是「认人全家桶」：掉刀、收刀、内番收工都能认出是哪位刀剑男士并记账；外加一波挂机稳定性大修。

## 出阵/挖地掉落自动认人（新功能）

- 出阵和挖地掉落刀剑时，自动认出是哪位，日志播报 🎉 并记进成绩单「全部记录」。
- 先确认是「获得画面」再认名字：战斗结算页的队伍成员栏不会再被误记成掉落（此前一晚上能记出一百多条假账）。
- 名牌比立绘晚几秒才到场也不漏：看到「发现了新的刀剑男士」横幅会耐心等名牌齐活再认。

## 锻刀收刀也认人（新功能）

- 收炉时认出是哪位刀剑男士来本丸，连这一炉的时长一起记账。

## 内番收工记录谁 +1（新功能，测试中）

- 内番跑完收工时读「内番报告」屏：谁涨了哪项属性，日志里播报 🎉。
- 每天顺手抄一遍六把刀的数值留档比对——属性喂满（金框）不冒 +1 徽章的情况也能从数值变化发现，成绩单里如实标注「数值比对发现」。
- 成绩单「全部记录」新增「内番收工」条目：谁 +1 一目了然；没人涨也记一条，方便以后查谁天天不干活。
- 该功能尚在测试中：认人以日志播报为准，认错或漏认不影响日课正常流程，看到离谱播报留个日志反馈即可。

## 安全保护：撤退和自动行军不再打架

- 同时勾着「王点前撤退」和「自动行军」时，引擎强制改手动行军兜底——以前撤退会静默失效直接进王点。

## 稳定性修理

- ADB 断线不再当场暴毙：发现内核猝死先自救（重启 ADB、重新连接，一场任务最多抢救 2 次），救不回来才按老规矩安全收场、打成绩单。
- 断网黑屏转樱花不再连环误判：认得加载状态，耐心等它转完（最长约 90 秒），超时如实报「断网/炸服」。
- 演练选阵改成双击阵形卡确认，不再因点空热点连环翻车；成绩单判分重写，「没跑却标绿」的假绿彻底堵死。
- 大阪城活动入口加载慢半拍不再放弃进图（加 4 拍重试）。
- 锻刀在刀位满时不再「只收不点火」。
- 资源总账对不上的缺口标记更老实，不再硬凑。
