# まあ丸 v0.3.5

内番收工谁涨了属性，现在会被认出来记进成绩单；挂机途中 ADB 断线不再当场暴毙。

## 内番收工记录谁 +1（新功能，测试中）

- 内番跑完收工时，まあ丸会读「内番报告」屏：谁涨了哪项属性，日志里播报 🎉。
- 每天还会顺手抄一遍六把刀的数值留档比对——属性喂满（金框）不冒 +1 徽章的情况，也能从数值变化里发现，成绩单里会如实标注「数值比对发现」。
- 成绩单「全部记录」新增「内番收工」条目：谁 +1 一目了然；没人涨也记一条，方便以后查谁天天不干活。
- 该功能尚在测试中：认人以日志播报为准，认错或漏认不影响日课正常流程，看到离谱播报留个日志反馈即可。

## ADB 断线不再当场暴毙

- 以前挂机途中网络波动、ADB 断开，内核会当场猝死，看门狗只能按章程收场。
- 现在发现猝死会先自救：重启 ADB、重新连接绑定，一场任务最多抢救 2 次；救不回来才按老规矩安全收场、打成绩单。

## 断网黑屏不再连环误判

- 游戏黑屏加载（左下角转樱花）时，以前导航会当成迷路，连环报错。
- 现在认得转樱花：耐心等它加载完（最长约 90 秒）；超时如实报「断网/炸服」，不乱点不误判。

## 升级说明

在まあ丸启动器中检查更新，下载并确认安装即可。升级不会删除现有的配置、成绩单、日志、排班或识别素材。
