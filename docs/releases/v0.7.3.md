# まあ丸 v0.7.3 更新公告

亲爱的审神者：

您好！まあ丸 v0.7.3 让秘宝之里的目标回到您自己手里：不必每期都照最高档硬算，现在可以按本期想要的奖励，自定义要攒多少玉。本次也带来了刀帐档案初版和两项盘点稳定性修正。

━━━━━━━━━━━━━━━━━━━━
一、秘宝之里
━━━━━━━━━━━━━━━━━━━━

1.【新增】可自定义本期玉目标。在「本丸 → 规划」的秘宝之里卡片中，展开「修改本期目标」，填入本期想攒到的玉数即可保存。

2.【调整】剩余玉、预计圈数、挂机时间、每日建议时长和小判上限，都会立即改按您的本期目标重算。

3.【调整】自定义目标只跟当期活动绑定。秘宝之里换期后，まあ丸会恢复按新一期的最高档奖励规划，不会沿用上期旧目标。

━━━━━━━━━━━━━━━━━━━━
二、刀帐档案初版
━━━━━━━━━━━━━━━━━━━━

1.【新增】完成刀帐盘点后，可在「配置 → 刀帐档案」查看整本刀帐。同名多振会各自保留，并按游戏内刀帐番号排列。

2.【新增】まあ丸确实分不清极化与普通形态时，会留在「等你拿主意」中，由您确认；不会拿等级或显现日期乱猜。机器没读到等级时，也可由您补入。

3.【新增】可先把想培养的成员标为「要练的刀」，为后续练级和编队功能留下玩家自己的选择。

━━━━━━━━━━━━━━━━━━━━
三、问题修正
━━━━━━━━━━━━━━━━━━━━

1.【修正】刀帐一览中某些页面的行距变化时，等级可能整列错到相邻成员身上。现在会按当页真实行位置读取，不再默默记错人。

2.【修正】连续两页有大量同名成员时，盘点可能误以为没有翻页。现在会额外核对页码条，避免提前收工。

3.【修正】电脑休眠或唤醒后，启动器的看门狗可能误判后台任务失联并强制停止。现在会正确识别这段时间跳跃，不再冤杀仍在工作的任务。

━━━━━━━━━━━━━━━━━━━━
四、升级须知
━━━━━━━━━━━━━━━━━━━━

1. Windows 版用户可在启动器中检查更新。升级只替换程序文件，不会删除 `%LOCALAPPDATA%\Maamaru` 中的配置、成绩单、手账、小记、规划目标、日志、排班、备份和识别素材。

2.刀帐档案仍是初版，极化/普通的人工确认和档案页会在后续版本继续改进；当前未确认项不影响既有自动任务。

3.「编队」相关功能仍处于科研阶段，尚不建议日常使用。

4. Android 离线试玩版仍是独立账房入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。
