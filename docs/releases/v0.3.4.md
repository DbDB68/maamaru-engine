# まあ丸 v0.3.4

这次给启动器换了新院子，同时修复资源账本里补充提灯跨日记漏账的问题。

## 启动器搬进了新院子

- 启动器换成庭院窗布局：检查项和功能分成左右两栏，一眼看清本丸状态。
- 下载更新时进度条变成狐狸跑道，显示真实下载进度；网络波动失败时可以直接重试，不用从头再来。

## 补充提灯不再漏记账

- 之前异去自动补充提灯后，这笔小判支出可能被记到次日「不知道谁干的」里，当天账目对不上。
- 现在账本会把补充前后的真实余额接进流水，跨天也能对上：当天记补充支出，次日从补充后的余额接着算。
- 成绩单日榜里连续多次相同的支出（比如一天补了好几次提灯）会折叠成一条，显示次数和合计，不再刷一长串。

## 升级说明

在まあ丸启动器中检查更新，下载并确认安装即可。升级不会删除现有的配置、成绩单、日志、排班或识别素材。
