# まあ丸 v0.1.7

这次把本丸面板整体翻修了一遍，也给活动出阵补上了不少新玩法。

## 新增

- 新增异去出阵，可配置地图、部队、行军方式、阵形与伤势停止条件。
- 新增大阪城挖地，可指定完成层数，并在通关 99 层后指定 1～99 层挂机。
- 大阪城支持自动或手动阵形、固定或有利阵形，以及受伤后的返回、手入和继续策略。

## 面板重构

- 主面板迁移至 Vue 3，重新整理任务选择、运行状态、日志和配置布局。
- 补充异去、大阪城等任务入口和专用图标。
- 优化窄屏布局、状态反馈及多处含义不清的文案。

## 修复

- 修复自动／手动阵形识别互相串台、战斗中反复切换的问题。
- 修复大阪城道中漏检伤势，以及层末画面判断和返回本丸流程。
- 修复轻伤可能被误判为重伤的问题，伤势识别只检查我方部队区域。
- 修复万屋暖心礼包因商品排版变化而误判售罄或点到其他商品的问题。
- 修复部分活动流程重复点击、空转和停止提示不准确的问题。

## 升级

在まあ丸启动器中检查更新，下载并确认安装即可。安装器只替换程序文件，不会删除
`%LOCALAPPDATA%\Maamaru` 中的配置、排班、日志和识别素材。
