# まあ丸 v0.3.0

这次不只是多记几笔数据：まあ丸开始会看小地图、会在王点前按约定收队，也终于把挂机经历和资源来往整理成了人能看懂的本丸成绩单。

## 王点前撤退

- 合战场新增「王点前撤退」。关闭自动行军后，まあ丸会读右上角小地图；确认下一步就是王点时，主动返回本丸，适合反复进图练级、避开检非违使。
- 已针对普通图、夜战、雨雾、市街图和复杂岔路补过识别规则。小地图一时认不清时会继续正常行军，不会把“不知道”当成撤退信号。
- 在「合战场」任务设置中打开开关即可；一键日课里的常驻合战场也会沿用这项设置。

> 这仍是基于画面识别的辅助判断。首次换地图或游戏界面有明显变化时，建议先在方便照看的情况下跑几圈。

## 本丸成绩单重做

- 成绩单改成「战报 / 资源账 / 全部记录」三层：先看最近一轮和主要玩法，再看家底变化，需要时才翻逐轮记录与完整时间线。
- 新增 24 小时、7 天、30 天和 1 年范围；轻量的玩法记录与审神者报备会长期保留，不会再到 90 天整批消失。体积较大的 OCR 观察明细仍默认保留 90 天。
- 最近事件会自动合并成玩家活动摘要，例如一段连续出阵、远征收取或任务奖励，不再拿一长串机器事件糊脸。
- 手机端恢复快速切换任务的左右翻页，桌面宽屏不会多出多余箭头。

## 资源账上线

- 新增八种资源总账：木炭、玉钢、冷却材、砥石、小判、甲州金、委托符和加速符。
- まあ丸现在会自动记录大阪城小判、异去补充提灯、远征结算、锻刀配方、手入消耗和任务奖励，并把“确认记得的收支”与“库存实际变化”分开显示。
- 没法完整对上的库存差值会明确留在账上，不会硬塞进某一轮挂机收益。审神者可以补一句大概做过什么，也可以选择暂不说明；报备只补上下文，不改写库存事实。
- 修正演练阵形确认、任务奖励领取确认，以及手入和任务奖励现场识别的多处兜底，避免成绩单把“点过”误当成“已经成功”。

## 升级说明

在まあ丸启动器中检查更新，下载并确认安装即可。安装器只替换程序文件，不会删除
`%LOCALAPPDATA%\Maamaru` 中的配置、排班、日志、成绩单数据与识别素材。

本次会随正式包补充小地图识别组件，安装包体积会比上一版有所增加。
