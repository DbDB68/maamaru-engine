# まあ丸 v0.2.2

这版把挂机成绩单从"只有大阪城能用"补成所有出阵玩法通用，并给每个玩法都加上开工/收工库存盘点，账才算得平。

## 异去

- 修复：每日首次进入异去的渐入剧情动画会把脚本打乱卡死。现在点"异去"后先等 2 秒，盯右下角"决定"按钮——被动画挡住就点安全区把动画跳完，再走章节选择。

## 库存盘点（run 级整体归因）

- 所有玩法（联队战、南瓜、合战场、异去、刷花、演练、远征、锻刀、手入、炼糖、一键日课）统一在开工前、收工后各盘点一次库存。
- 任务自然失败时也会尽力补拍收工快照（中途可能已消耗资源）；紧急停止/看门狗强杀没有机会补拍，成绩单会提示缺收工快照。
- 每个脚本 = 一轮任务，只算这一轮的资源变化，不再和别的任务混账。

## 成绩单

- 挂机成绩单不再只显示大阪城：异去、合战场、联队战、南瓜、一键日课都会记录并显示。
- 有前后库存快照但资源无变化时，明确显示"本轮资源无变化"，不再空白。
- 窄屏下日志面板固定高度，不再出现"日志 +1、页面 +1"的无限变长。

## 升级

在まあ丸启动器中检查更新，下载并确认安装即可。安装器只替换程序文件，不会删除
`%LOCALAPPDATA%\Maamaru` 中的配置、排班、日志、统计数据与识别素材。
