# まあ丸 v0.3.1

这次把成绩单从“看个总数”继续做成能翻、能点、能解释的一本资源账；普通任务收工时也会主动回本丸看一眼家底。启动器则换上了正式图标和更清楚的就绪页面。

## 资源账更好查了

- 资源收支改成按来源染色的柱状图。远征、锻刀、手入、任务报酬、审神者报备等来源分开显示，点某一天的柱子就能查看当天明细。
- “全部记录”新增按日期浏览。切到某一天时，只加载当天的任务和单独记录，不必在整段历史里来回翻找。
- 日期范围和统计口径进一步整理：跨日任务、只有确认收支但没有完整库存读数的日期，也会保留在图表和记录中。

## 家底变化可以直接说明

- 图表里的灰色部分表示库存确实发生了变化，但まあ丸还不知道原因。现在点灰色柱子会直接打开当天的报备表单，并滚动到填写位置。
- 即使某一天没有待认领差额，也可以主动补充“这段时间我做过什么”。说明只补上下文，不会改写库存实际变化或冒充某轮挂机收益。
- 资源增减、确认来源和未说明差额的汇总方式已经统一，切换日期和资源时不再出现统计口径跳动。

## 收工会回本丸看一眼

- 普通任务和一键日课结束后，会尝试导航回本丸，并强制读取一次顶栏资源，作为这次任务结束的家底观察点。
- 如果收尾没能回到本丸，会在日志里给出醒目提醒；收尾失败不会抹掉已经完成的任务结果。
- 紧急停止会直接结束任务进程，无法保证执行这一步，停止后仍建议看一眼模拟器当前页面。

## 启动器焕新

- 启动器换上新的まあ丸图标，并重新整理了“准备好了”“还差一步”和启动过程的提示。
- 正常项目收进折叠区，需要处理的问题优先展示；窗口尺寸也调整得更适合直接进入本丸面板。

## 升级说明

在まあ丸启动器中检查更新，下载并确认安装即可。安装器只替换程序文件，不会删除
`%LOCALAPPDATA%\Maamaru` 中的配置、排班、日志、成绩单数据与识别素材。
