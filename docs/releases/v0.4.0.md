# まあ丸 v0.4.0

这次本丸不只替你干活，也开始帮你记着“接下来想做什么”：活动日程、资源目标和成绩单放到了一起；江户城也终于能自己进去巡游了。

## 江户城智能 E4（新功能，测试中）

- 江户城只智能跑 E4，其他难度不计划适配：读取剩余步数，按路线踩点、取钥匙并前往王点。
- 可以选择部队、出阵次数、阵形策略和是否使用小判补充手形；没有明确开启时不会消耗小判。
- 出阵仍经过选队确认、伤势检查、刀装处理和重伤拦截；中伤可按江户城的虚拟伤害规则继续，确认重伤时停止。
- 每圈结算会记录带回的钥匙、耗时和圈数，成绩单里可以展开查看。
- 这是第一次随正式版本发布，当前路线和识别范围按本期 E4 实机画面制作。目前 4 圈记录共带回 90 把钥匙，场均 22.5 把，少量样本表现不错但仅供参考；活动复刻、游戏更新或首次使用时请先短跑一圈。

## 本丸规划与活动日程（新功能）

- 本丸新增“规划”页，先展示已经立下的目标，再展示活动日程和操作入口。
- 自定资源目标可以选择“攒到多少”或“到哪一天”：一个由玩家决定，另一个交给狐之助按近期净收支估算。
- 活动日程会整理进行中和即将开始的官方活动；暂时联系不上日程服务器时沿用本地旧数据并明确提示。
- 活动日期使用独立活动期次保存，复刻时不会直接借用另一届的实测结果。

## 江户城与大阪城算盘（新功能）

- 江户城按钥匙目标、场均钥匙、免费手形和精确结束时刻估算需要补多少手形、准备多少小判。
- 本期实测钥匙会优先进入算盘；还没跑过时可以先填一个场均估计，之后由实测自动接手。
- 大阪城可以把“活动结束时想留下多少小判”立成目标，由当前家底反推还差多少、约需多少层和多少挂机时间。
- 预算、库存目标和截止时间均由后端统一计算，前端不再自己拿“家底 + 预算”拼答案。

## 收杂物箱（新功能）

- 新增独立“收杂物箱”任务，只领取资源、货币、便利道具和其他物品。
- 刀剑邮件会原样留在收件箱，不会因为收杂物顺手带走。
- 收完会补一份库存快照，并把能够确认的资源变化记进成绩单。

## 成绩单重新收拾了一遍

- 成绩单与规划合并到“本丸”，资源对账、全部记录、目标和活动日程不再散落。
- 掉落和入手结果不再在多个位置重复铺开；全部记录仍可按日期查看完整来路。
- 玩家说明现在会精确对应资源、日期和数量，不会因为解释一项资源就把同一天其他资源一起染成已说明。
- 江户城完成圈数、实际耗时和每圈钥匙进入任务明细；无法确认的收支继续保留为未知。

## 挂机稳定性

- 新增 MuMu 显存截图通道，避免部分环境下 ADB 截图只拿到半张画面；连续失败时仍会退回普通截图。
- 大阪城修正层末转场的幽灵圈、行军按钮短暂缺席、选阵页面离场等问题。
- 活动时间、预算目标和旧规划数据补充了兼容与迁移检查，老用户升级后不需要重建立目标。

## 升级说明

在まあ丸启动器中检查更新，下载并确认安装即可。升级只替换程序文件，不删除现有配置、成绩单、规划目标、日志、排班或识别素材。

江户城、活动日程和目标预测都依赖本期真实画面与现有记录。第一次运行江户城、开启小判补票或依据预测安排长期挂机前，请先短跑确认页面识别、伤势规则和停止条件符合自己的本丸。
