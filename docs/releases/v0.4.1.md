# まあ丸 v0.4.1

这次主要把江户城从“能跑”收拾到“可以稳定跑”：出阵、补手形、入场战斗、阵形选择、战后结算和回地图的每一段都重新按真实画面校准了一遍。共用战斗流程也顺手补上了几处容易被页面动画和旧截图带偏的问题。

## 江户城稳定性

- 战斗结束后不再固定连点跳过，而是先等战果出现，再按 0.9 秒节奏逐页跳过结算和钥匙／步数横幅；地图已经回来后立即停手。
- 回到地图后以左下角“地图点选择”文字确认页面真的可以操作，钥匙点弹出对话时不会提前点击下一节点。
- 出阵确认后若先遇到入场战斗，会在阵形选择页立即停止点击并正常打完；手动和自动阵形都能识别，不会把某一种模式当成唯一页面标志。
- 部队选择改为使用当前画面重新确认，不再拿上一帧的按钮坐标误点“即刻出阵”。
- 没有手形时复用联队战的三段补充流程：补充一张、确认消耗、重新出阵；补完后会再次等待真正的出阵确认。
- 出阵确认页优先于补票按钮判断，避免相似按钮或页面残影把正常确认误当成缺票。

## 共用战斗与活动入口

- 阵形设置收束为“自动／手动”和手动兜底阵形两个明确选项；自动索敌失败时仍能选择有利阵形或使用兜底阵形。
- 阵形页增加加载稳定检查，减少标题晚出现、切换模式重绘和快速点击造成的误判。
- 部队选择按钮增加 OCR 识别，右上角暖心礼包出现时也能正确关闭。
- 概览中的季节活动入口会按当前活动状态显示；活动名称按包含关系匹配，减少公告名称略有变化时入口消失。
- 日课、远征、奖励领取、大阪城、南瓜和普通出阵补充了共用页面恢复与失败记录检查。

## 升级说明

在まあ丸启动器中检查更新，下载并确认安装即可。升级只替换程序文件，不删除现有配置、成绩单、规划目标、日志、排班或识别素材。

江户城仍然只智能跑 E4，其他难度不计划适配。虽然本版已完成多轮真实画面修复和一圈完整实机验证，游戏活动页面仍可能随更新变化；升级后第一次开启补手形或长时间运行前，建议先短跑一圈。
