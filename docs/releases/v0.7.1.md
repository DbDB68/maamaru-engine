# まあ丸 v0.7.1 更新公告

亲爱的审神者：

您好！まあ丸 v0.7.1 继续把“本丸管家会干活，也会把做过的事说清楚”往前推了一步。本次加入刀帐盘点与更可靠的逐圈记录，并让秘宝之里的换队长和三十万玉规划真正落到日常使用中。

━━━━━━━━━━━━━━━━━━━━
一、新增功能
━━━━━━━━━━━━━━━━━━━━

1.【新增】刀帐盘点。まあ丸可以只读扫描刀剑男士一览，把所持刀剑、等级、乱舞等级、生存与疲劳等资料整理成快照；认不清的行太多时不会强行入账。盘点结果可在成绩单的“所持刀剑”中查看，并会核对游戏所持数，重复持有的同名刀剑也不会被误删。

2.【新增】秘宝之里换队长。可在活动设置中开启队长轮换，并设置等级差余量；まあ丸会沿用通用的安全出阵检查，不会绕过重伤拦截或刀装处理。

3.【新增】逐圈 Run Record。普通出阵等玩法每次真正出发后会留下结构化记录，包括地图、部队、战斗数、耗时、掉落和结果；同一次出发中获得的刀剑会归到对应圈次，未知结果不会被伪装成成功。

━━━━━━━━━━━━━━━━━━━━
二、规划与账房
━━━━━━━━━━━━━━━━━━━━

1.【调整】秘宝之里固定以最高档 `300,000 玉` 为目标，不再要求玩家填写目标玉数。

2.【新增】活动卡会根据本期真实跑圈记录，显示当前累计玉、剩余玉、平均每圈、预计圈数、挂机时间、未来免费令牌和保守的小判上限。样本不足时会继续记账，不会拿占位数字冒充估算。

3.【调整】小判预算明确说明当前尚未读取手头令牌，因此先按手头 0 张保守计算；实际需要补的令牌和小判只会更少，不会把上限误写成精确支出。

━━━━━━━━━━━━━━━━━━━━
三、问题修正
━━━━━━━━━━━━━━━━━━━━

1.【修正】刀帐盘点按真实行身份保留同名多把，不再因为名字相同就错误去重；已完成 196/196 的实机对账。

2.【修正】逐圈战斗计数统一观察所有运行帧，掉落识别或返回本丸期间出现的结算页不再漏算；掉落也会带上本次出发编号，避免中断重试后串圈。

3.【修正】成绩单会如实区分未闭合、未知结果和已完成记录，不把外部关闭或崩溃后的半圈写成成功。

━━━━━━━━━━━━━━━━━━━━
四、升级须知
━━━━━━━━━━━━━━━━━━━━

1. Windows 版用户可在启动器中检查更新。升级只替换程序文件，不会删除 `%LOCALAPPDATA%\Maamaru` 中的配置、成绩单、手账、小记、规划目标、日志、排班、备份和识别素材。

2. 刀帐盘点是只读功能，不会锁定、刀解、习合或修改刀剑；第一次建议在 1280×720 的 MuMu 12 环境下观察一轮对账结果。

3. 秘宝之里小判预算暂未读取手头现有令牌，卡片展示的是按 0 张起算的保守上限；每日 5:00、17:00 各恢复 3 个令牌。

4. Android 离线试玩版仍是独立账房入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。
