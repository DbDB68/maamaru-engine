# まあ丸 v0.6.2 更新公告

亲爱的审神者：

您好！まあ丸 v0.6.2 现已正式发布。本次为可靠性修整版，重点修复出阵选图与活动记账中的多处隐患。更新内容如下：

━━━━━━━━━━━━━━━━━━━━
一、问题修正
━━━━━━━━━━━━━━━━━━━━

1.【修正】异去与合战场选图不再被游戏「记忆上次所选」坑害。游戏默认选中上次打的小图时，脚本再点一次会直接跳进部队选择页，导致找不到按钮、任务失败。现已改为先看清当前界面状态再行动，跳级进场、误触跳页均能自行接住。

2.【修正】万屋购买不再盲点坐标。购买前必先确认当前页面与商品位置，点错页签、误购道具的风险已排除。

3.【修正】远征选图必先验证地图页状态，不再出现选错远征地点白跑一趟的情况。

4.【修正】江户城潜入调查的实测场均钥匙恢复统计。此前每圈记账的期次标签写错，打多少圈都被当成「别届活动」丢弃，活动卡只能手填估计。现历史数据自动归位，场均钥匙即刻恢复实测。

5.【修正】执务页「常用功能」自定义排序不再错位。此前上下移动自定义工作流时，实际移动的是炼糖、刷花模块。

━━━━━━━━━━━━━━━━━━━━
二、优化改进
━━━━━━━━━━━━━━━━━━━━

1.【优化】模拟器无头运行时 ADB 端口异常可自愈：16384 端口不应答时自动改走备用通道，不再整夜呆坐空转。

2.【优化】异去活动预算卡文案说人话：「大约用时」与「每天留多少时间」各司其职，并按计算模式展示对应结果（按时间报免费提灯可打次数，按圈数报总时长与每日均摊）。

━━━━━━━━━━━━━━━━━━━━
三、升级须知
━━━━━━━━━━━━━━━━━━━━

1. Windows 版用户可在启动器中检查更新。升级不会删除配置、成绩单、手账、小记、规划目标、日志、排班、备份及识别素材，请放心升级。

2. Android 离线试玩版（maamaru-ledger-demo-v0.6.2.apk）随本版继续提供，仍为独立试玩入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。

3. 正常管家模式仍主要支持 MuMu 12 与 1280×720 游戏画面；江户城仍只智能跑 E4，其他难度暂无适配计划。

━━━━━━━━━━━━━━━━━━━━
