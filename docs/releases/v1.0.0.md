# まあ丸 v1.0.0 更新公告

亲爱的审神者：

您好！まあ丸迎来了第一个正式版本。这次把本丸近况、刀账、账房与规划串在一起，让记录能帮上忙，也让回到本丸时多一点生活感。

## 我的本丸

- 本丸动态会整理确认过的锻刀结果、出阵掉落、收件箱收刀、远征归来和刀剑整理记录，留下刀名、来处与收获；您也可以写自己的小记。
- 首页展示归期、资源安排与活动进度，常用页面按「规划 → 功能 → 仓库 → 刀剑」排列。

## 规划与定时开工

- 联队战建议圈数可以直接安排进时间表，按安排的圈数执行，默认允许补充手形；定时任务流单独添加，按任务流保存的设置运行。
- 定时联队战会准备模拟器、登录并处理本丸弹窗；已有任务没结束时排队接上。安排可修改或移除。
- 狐之助的资源建议与远征推荐使用同一个关注项，手动修改关注项也会影响远征建议。目标资源暂时排不出时，会说明刀种、总等级或地图占用的限制。
- 远征可套用已有部队预设；联队战超过免费手形的预计小判支出会计入预算。

## 刀账与账房

- 刀账优先使用游戏记录中的所持名单和每振刀的唯一编号，同名刀分别记录。旧标注能唯一对应时保留；已经离开本丸的刀保留为历史标注。
- 确认过的锻刀、战斗掉落与收件箱领取会记入收刀记录；链结、习合与刀解会按实际消耗的那一振更新名单。
- 账房翻译游戏中的资源、物品与活动点数记录，并区分游戏记录和まあ丸执行记录，展示更具体的来源。
- 游戏记录在同步或相关任务收工时读取，并非实时监听。拉取的原始客户端日志解析后删除，只保存所需记录。

## 出阵与自动行军

- 脚本关闭自动行军时，会检查并关闭游戏记住的委托状态。
- 使用自动行军时，会同步游戏内的伤势、刀装与兜底阵形设置；重疲劳停止为独立开关，默认开启。
- 阵形选择旁增加能力变化提示。伤势仍以出阵前的画面识别与安全检查为准，不把活动虚拟伤害当作本丸伤势。

## 升级说明

Windows 用户可在启动器中检查更新，或下载下方安装器。升级只替换程序，保留 `%LOCALAPPDATA%\Maamaru` 中的配置、记录与备份；缺少的新配置项会先备份再补齐。

部队预设与换装仍建议先短跑确认，身份或装备读不清时会停在出发前。Android 离线试玩版仍是独立账房，不连接游戏，也不与电脑端同步。
