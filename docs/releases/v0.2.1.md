# まあ丸 v0.2.1

这次继续给“本丸成绩单”打地基：让长时间挂机的收工记录更可靠，也把狐狸自动完成的事、库存实际变化和审神者自己的操作分开记录。

## 成绩单与库存

- 挂机成绩单新增实际出阵用时、小判每小时收益，并继续提供按时长估算圈数。
- 开工与收工库存快照会计算本轮资源变化；收工盘点失败时，可将最近一次未受其他操作污染的库存快照安全补到最新轮次。
- 两轮任务之间出现非零库存差值时，まあ丸会单独提醒；差值不会被算进任何一轮挂机收益。
- 审神者可以只按大概时间报备做过什么，无需手工填写资源数字，也可以跳过说明、只保留差值事实。
- 狐狸账、库存账和审神者报备彼此独立，不会互相改写。

## 长时间挂机

- 出阵结束回本丸时最长等待 90 秒，避免长时间挂机后的加载过程导致收工盘点过早失败。
- 收工快照会再次独立确认本丸目录已经可用，超时则明确放弃本次盘点，不制造假数据。

## 演练

- 会识别当前刷新场已经留下的“胜利／败北”记录，已有胜场可计入目标，避免重复挑战。
- 成绩单分别显示胜、负和未识别场次，不再把无法确认的结果直接显示成 `0 / 3`。

## 升级

在まあ丸启动器中检查更新，下载并确认安装即可。安装器只替换程序文件，不会删除
`%LOCALAPPDATA%\Maamaru` 中的配置、排班、日志、统计数据与识别素材。
