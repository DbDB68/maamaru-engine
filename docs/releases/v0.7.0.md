# まあ丸 v0.7.0 更新公告

亲爱的审神者：

您好！まあ丸 v0.7.0 现已正式发布。本次更新加入秘宝之里自动跑圈，也把大家反馈较多的锻刀、日课、模拟器连接和运行记录一起理顺。更新内容如下：

━━━━━━━━━━━━━━━━━━━━
一、新增功能
━━━━━━━━━━━━━━━━━━━━

1.【新增】秘宝之里自动跑圈。选择难度、部队和出阵次数后，まあ丸会挂上游戏内委托并看守整圈；令牌不足时安全收工，只有明确开启补充后才会使用小判。

2.【新增】限锻十连模式。支持自定义锻刀次数、炉位数量、配方和加速符；刀位接近上限时，可选择停止、仅刀解白名单刀剑，或用当前库存进行习合。

3.【新增】系统设置中可以手动填写 ADB 地址。留空时仍会自动寻找模拟器，手填后可直接测试连接。

4.【新增】自定义工作流名称会显示在成绩单中，误跑或翻车留下的运行记录也可以手动删除；秘宝之里等单独成绩会直接写明难度、部队、圈数和带回的玉，不再只显示“本丸记录”。

━━━━━━━━━━━━━━━━━━━━
二、问题修正
━━━━━━━━━━━━━━━━━━━━

1.【修正】自定义安装目录更新时不再因程序根目录不匹配而崩溃。由旧版本升级到本版时，请先在 Releases 手动下载安装包覆盖安装一次；配置和记录不会丢失，此后自动更新即可正常使用。

2.【修正】一键日课的锻刀配方、次数和出阵行为各自生效，不再借用「配置」页设置，也不会因为流程里没有安排手入却自行修刀。

3.【修正】限锻遇到确认弹窗不再卡住；每批开始前都会重新确认刀位，无法确认时安全停止，不会盲目消耗资源。

4.【修正】从签到页、公告页或修行申请弹窗启动一键日课时可以正常清场；修行申请会自动选择暂不启程。

5.【修正】江户城节点点击后会继续观察迟到的战斗，不再把战斗误当成普通地图状态。

6.【修正】异去里程碑奖励弹窗能够自动领取，累计圈数也会按首次读取的基线继续记录。

7.【调整】江户城和秘宝之里的「出阵次数」恢复为普通正整数设置，不再让 `0` 承担“把令牌跑完”的隐藏含义。未开启补票时，手形或令牌不足会提前收工；开启后也只补足设定次数。

8.【调整】秘宝之里使用原创花札图标，不再拿游戏令牌截图充当界面素材。

9.【修正】普通锻刀的「目标时长」设置恢复可填写：按时、分、秒添加关注时长，点一下就能删掉；设了时长后，锻出目标刀会向手机报喜。日课独立配置里的锻刀次数上限也与锻刀步骤统一（最多 200）。

━━━━━━━━━━━━━━━━━━━━
三、升级须知
━━━━━━━━━━━━━━━━━━━━

1. 本次包含更新助手修复。若旧版安装在自定义目录，请从本页手动下载安装包并覆盖安装一次；升级过程不会删除 `%LOCALAPPDATA%\Maamaru` 中的配置、成绩单、手账、日志、排班和备份。

2. 秘宝之里依赖游戏内「委托」自动行军；若委托未能挂上，まあ丸会停止出阵，不会改用盲点方式硬跑。

3. Windows 版仍主要支持 MuMu 12 与 1280×720 游戏画面。Android 离线试玩版仍是独立账房入口，不会唤醒模拟器、ADB、MAA 或任何游戏脚本。
